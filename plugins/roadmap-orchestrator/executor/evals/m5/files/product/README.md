# Swapshelf

The page for the book swap shelf outside 14 Oak Street. Neighbours see what is on the shelf; the keeper looks after it.

    npm start          # http://127.0.0.1:3000/ (PORT and SWAPSHELF_DATA override the port and the data file)
    npm test

No dependencies: Node 24 and nothing else. What it is for and where it is going: `docs/corpus/`.
