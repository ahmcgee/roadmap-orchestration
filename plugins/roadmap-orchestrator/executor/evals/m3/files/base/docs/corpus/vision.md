# Vision

Bookkeepers reconcile a month in one command. Money is never silently mis-rounded. Clear errors come before
permissive input.

At month-end a bookkeeper runs one command over the month's ledger and gets a balance she can file without re-adding
it by hand: every amount is exact to the cent, and a bad entry stops the run with a message naming it, so closing the
books takes minutes instead of an afternoon.
